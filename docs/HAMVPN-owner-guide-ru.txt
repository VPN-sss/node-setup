HAMVPN · Как проверить и закрепить версию VPN для компьютера
Памятка владельцу · 19 ноября 2026

Эта инструкция — для сервера, на котором VPN уже установлен. Если VPN
работает и сайты в Koala открываются, переустанавливать ничего не надо.
Работайте только с одним сервером за раз. Остальные пока не трогайте.

1. Убедитесь, что проверяете нужный сервер

   На компьютере откройте Koala Clash. Выберите сервер по названию вручную,
   а не «Автовыбор». Запишите название и откройте два разных сайта.
   Если оба открылись, остановитесь: для этого сервера работа закончена.
   Если не открылись, а через другой сервер открываются, переходите к шагу 2.

2. Откройте консоль сервера

   Понадобится доступ к серверу от хостинга. На Windows откройте «Терминал»
   или PowerShell. Если хостинг дал логин root и обычный порт 22, введите:

   ssh root@IP_СЕРВЕРА

   Замените IP_СЕРВЕРА на настоящий адрес из кабинета хостинга.
   Если указан другой порт, например 2222, команда: ssh -p 2222 root@IP_СЕРВЕРА
   Это должен быть именно SSH-порт из кабинета, не порт VPN.
   При первом подключении сверьте отпечаток ключа с данными хостинга.
   Если ключ изменился или не с чем сверить, не подтверждайте наугад.
   Можно вместо SSH открыть консоль нужного сервера в кабинете хостинга.

   При вводе пароля на экране не появляются даже звёздочки — это нормально.
   Пароль вводите только в окне входа. Никому не пересылайте его в Telegram.
   После входа введите: whoami
   Если ответ root — всё готово. Если другой логин — введите sudo -i и снова
   whoami. Если права не выданы, дальше не продолжайте.

   Важно: все команды ниже вводятся в консоли СЕРВЕРА, не в Koala
   и не в обычном окне Windows с приглашением PS C:\...>.

3. Скачайте проверенную версию установщика

   Скопируйте следующую длинную строку целиком и нажмите Enter один раз:

   HAM_DIR=$(mktemp -d /root/ham-node-setup.XXXXXX) && git clone --quiet https://github.com/VPN-sss/node-setup.git "$HAM_DIR" && cd "$HAM_DIR" && git checkout --quiet --detach e85de59a19fe4163ffb1b7fc5803d3413ebff45a && pwd

   В конце должен появиться путь вида /root/ham-node-setup.Ab12Cd.
   Запишите СВОЙ путь: он понадобится, если закроете консоль. Если вместо
   пути видите ошибку, например «git: command not found», остановитесь.
   Скачивание само по себе VPN не меняет.

4. Проверьте состояние, затем выберите нужное действие

   bash install.sh --status

   Эта команда ничего не меняет. Если указаны 26.7.28, process OK, mount OK
   и совпадение работающего ядра, нужное ядро уже работает. Если сайты при этом
   не открываются, не ставьте ту же версию повторно: причина не установлена.
   Сообщение «Нет файла фиксации HAM» само по себе НЕ говорит о поломке
   или о версии. Посмотрите версию Xray именно этой ноды в панели VPN.

   Если на проблемной ноде действительно стоит 26.10.31 или 26.11.9,
   а требуется проверенная для Koala версия 26.7.28, запустите:

   bash install.sh

   Дождитесь каждого вопроса. Не вставляйте ответы одной строкой.
   • Язык                     → 1, затем Enter (Русский)
   • Действие                 → 2, затем Enter (Смена Xray)
   • Версия                   → 2, затем Enter (Проверенный Xray 26.7.28)
   • Продолжить с 26.7.28?    → y, затем Enter (латинская буква)

   НЕ выбирайте «Новая нода». Если скрипт спрашивает домен или предлагает
   установить сайт, это не тот режим. Нажмите Ctrl+C и не продолжайте.
   Смена ядра ненадолго прерывает соединения через эту ноду.

5. Дождитесь сообщения «Версия закреплена». Второго вопроса нет.

   Сохраните путь из PREPARED_STATE=... для ручного возврата. Таймер
   не создаётся. Проверьте результат командой bash install.sh --status:
   ожидаются version 26.7.28, mount OK и process OK.
   Выберите ту же ноду вручную в Koala, откройте два HTTPS-сайта,
   проверьте выходной IP. Если связь не работает — используйте ручной откат.

Если нужно вернуть прежнюю версию вручную

   Только на той же ноде, из папки установщика. Введите первую команду,
   нажмите Enter и вставьте путь ПОСЛЕ знака = из вашей строки PREPARED_STATE.
   Не используйте путь из чужого примера или с другого сервера.

   read -r -p 'Вставьте путь PREPARED_STATE: ' HAM_STATE
   python3 corectl.py rollback --state "$HAM_STATE"

   После отката переподключитесь в Koala. Если скрипт отказался выполнять
   откат из-за изменённой конфигурации, ничего не удаляйте вручную.

Как проверить завтра

   Подключитесь к этому же серверу, войдите как root и введите cd, пробел
   и свой путь из шага 3. Затем: bash install.sh --status
   Если версия отличается или появляется DIFF, не переустанавливайте сразу.
   Сохраните название ноды, время и вывод этой проверки. Пароль, приватный
   SSH-ключ, токены и личную ссылку подписки к отчёту не прикладывайте.
