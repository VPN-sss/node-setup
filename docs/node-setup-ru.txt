HAMVPN | Установка ноды и смена версии Xray

Установщик запускается по SSH на самом сервере. Для нового сервера используйте
«Новую ноду», для уже работающего — «Смену Xray». Если нужно только узнать
состояние, выберите «Диагностику»: она ничего не устанавливает и не перезапускает.

ЗАПУСК СКРИПТА

Команды ниже рассчитаны на Ubuntu/Debian с Git. Войдите по SSH с правами root.
Если вошли под другим пользователем с правами sudo, сначала выполните sudo -i.

Первый запуск на этом сервере:
  git clone https://github.com/VPN-sss/node-setup.git /root/node-setup && cd /root/node-setup && bash install.sh

Последующие запуски:
  cd /root/node-setup && git pull --ff-only && bash install.sh

Если скрипт уже скачан в другую папку, используйте её вместо /root/node-setup.
Если обновление Git завершилось ошибкой, не удаляйте папку: в ней могут быть
локальные настройки. Обновление самого скрипта не меняет версию Xray на ноде.

1. УСТАНОВИТЬ НОВУЮ НОДУ

До запуска подготовьте IP сервера и SECRET_KEY для ноды из панели Remnawave.
Это ключ подключения ноды, не API-токен панели. Если SSH работает не на порту
22, заранее разрешите свой SSH-порт в firewall, чтобы не потерять доступ.

  1) Язык → «1. Русский». Действие → «1. Новая нода».
  2) Версия ядра → «1. Последний Xray» или «2. Проверенный Xray 26.7.28».
     Для совместимости со старыми клиентами Koala Clash/mihomo проверялся
     вариант 26.7.28. Это не рекомендация ставить старое ядро на любой сервер.
     Подтвердите выбор латинской y. Enter в меню версий отменяет установку.
  3) На вопрос про self-steal ответьте по схеме этой ноды:
     • Нет — установка без собственного сайта и сертификата. Введите SECRET_KEY,
       а при запросе SNI — доменное имя целевого HTTPS-сайта из вашей схемы,
       без https:// и пути.
     • Да — установка со своим доменом, сайтом и сертификатом. Заранее направьте
       DNS-запись домена на сервер. Скрипт запросит домен, почту для сертификата
       и SECRET_KEY. При выборе DNS-проверки через Cloudflare потребуется токен
       с правом изменения DNS только для нужной зоны.
  4) После установки подключите ноду в Remnawave: укажите адрес сервера и порт
     управления 2222. Разрешите доступ к этому порту со стороны панели.
     Импортируйте /opt/remnanode/profile-template.json как отдельный профиль
     и назначьте его новой ноде. Не затирайте общий профиль других нод.
     В клиентском хосте выберите вход из этого профиля: порт 443, SNI из шага 3,
     отпечаток firefox. Файл профиля содержит приватный ключ — не отправляйте в чат.
  5) Обновите подписку в клиенте, выберите именно новый хост и откройте
     несколько HTTPS-сайтов. Статус Connected в панели подтверждает связь
     панели с нодой, но не заменяет эту проверку.

2. СМЕНИТЬ XRAY НА РАБОТАЮЩЕЙ НОДЕ

  1) Запустите скрипт. Язык → «1. Русский». Действие → «2. Смена Xray».
     Этот режим не переустанавливает сайт. Смена ядра кратко прервёт
     подключения через эту ноду; меняйте серверы по одному.
  2) Выберите нужную версию и подтвердите латинской y. Сохраните путь,
     который скрипт напечатает после PREPARED_STATE=. Он нужен для отката.
  3) Дождитесь сообщения «Версия закреплена». Повторного подтверждения нет.
     Если проверка ядра после запуска не пройдёт, скрипт попробует вернуть
     прежнюю конфигурацию сразу. Возврата по таймеру нет.
  4) Выберите этот хост в клиенте без автовыбора, откройте два разных
     HTTPS-сайта и проверьте выходной IP. Если сайты не открываются,
     используйте раздел «Ручной откат». Не удаляйте .ham-xray.


ПРОВЕРИТЬ РЕЗУЛЬТАТ

  cd /root/node-setup && bash install.sh --status

После закрепления ожидаются выбранная версия, mount OK, process OK и сообщение,
что ядро закреплено. При DIFF скрипт обнаружил расхождение, но ничего не
исправил автоматически. Сохраните вывод до повторной установки.

РУЧНОЙ ОТКАТ

На той же ноде, из папки того же установщика, которым меняли версию:
  read -r -p 'Путь после PREPARED_STATE=: ' HAM_STATE
  python3 corectl.py rollback --state "$HAM_STATE"

При первом запросе вставьте только сохранённый путь этой операции. После
отката переподключитесь в клиенте. Если скрипт сообщает, что конфигурация
изменилась, не удаляйте Compose-файлы и каталог .ham-xray вручную.
